GEEZMO'S SUPPLY — WEBSITE DEMO

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder geezmos_supply_website.
3. Klik dua kali index.html atau buka dengan browser.
4. Website dapat dibuka di laptop dan HP (responsive).

ISI WEBSITE
- Beranda dan identitas toko
- Tentang Kami
- Katalog 3 produk dengan nama, deskripsi, dan harga dummy
- Keranjang belanja sederhana
- Checkout simulasi melalui WhatsApp
- Kebijakan pengiriman, retur/refund, privasi, pembayaran
- Kontak, tautan media sosial, dan formulir email

WAJIB DIGANTI SEBELUM DIPUBLIKASIKAN
- Nomor WhatsApp demo: 6281200000000 (di script.js)
- Email: hello@geezmossupply.com (di index.html dan script.js)
- Alamat toko
- Nama/foto/deskripsi/harga produk
- Link Instagram dan TikTok
- Sesuaikan kebijakan toko dengan aturan bisnis sebenarnya.

CATATAN PENTING
- Data saat ini dummy untuk rancangan tugas.
- Keranjang dan checkout hanya simulasi front-end; belum terhubung database, payment gateway, atau sistem stok.
- Form kontak membuka aplikasi email, bukan menyimpan data ke server.
- Tombol admin/database tidak disertakan karena perlu backend dan autentikasi.
- HTTPS aktif setelah website diunggah ke hosting/domain yang menyediakan SSL.
- Untuk memenuhi unsur legalitas, tambahkan NIB hanya jika benar-benar tersedia dan valid.
